# The BlackBook

Website for The BlackBook – a small business directory focused on Black-owned businesses, with The Black Market e-store.

- `index.html` – the full site (single self-contained page: directory, The Black Market shop with cart, Things to Do, Rewards Card, List Your Business, Contact).

To view it, open `index.html` in a browser. To host it free, turn on GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main`).
